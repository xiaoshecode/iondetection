两方法在 2 像素内的一对一配对共 524363 对，覆盖各自候选的 92.81% 和 93.93%，已配对中心的平均距离为 0.289 像素。这些指标表示算法一致性；没有逐离子独立真值，不能据此报告准确率，也不能将文件夹名中的 2000 当作每帧真实数量。

原运行总结记录了 masked 在上下图像边界的候选聚集现象。恢复图更平滑尚不能证明定位更准确；完整观察、强度尺度和适用边界见 [识别结果总结.txt](识别结果总结.txt)。
